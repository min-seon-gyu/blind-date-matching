# B2B 소개팅 매칭 플랫폼 사용자 가이드

## 서비스 소개

오프라인 소개팅 이벤트를 운영하는 카페/바에 매칭 시스템을 제공하는 B2B 플랫폼입니다. 카페 주인, 소개팅 주관자, 참가자를 연결합니다.

---

## 참가자 가이드

### 1. 회원가입 / 로그인

- **카카오 계정**으로 간편 로그인합니다.
- 처음 로그인하면 자동으로 회원가입이 완료됩니다.

### 2. 프로필 설정 (최초 1회)

| 항목 | 필수 | 설명 |
|------|------|------|
| 이름 | O | 실명 |
| 나이 | O | 만 나이 |
| 성별 | O | 남성 / 여성 |
| 직업 | O | 현재 직업 |
| 키 | - | cm 단위 |
| MBTI | - | 4자리 (예: ENFP) |
| 취미 | - | 자유 입력 |
| 음주 | - | 안 함 / 가끔 / 자주 |
| 흡연 | - | 안 함 / 가끔 / 자주 |
| 종교 | - | 자유 입력 |
| 이상형 | - | 원하는 상대에 대한 설명 |
| 자기소개 | - | 자유롭게 작성 |
| 프로필 사진 | - | 이미지 업로드 |

### 3. 이벤트 참가

- 카페별 이벤트 페이지(`/cafes/{slug}`)에서 이벤트를 확인합니다.
- 이벤트 정보: 제목, 날짜, 시간, 남녀 정원, 참가비, 연령 제한
- 카카오맵으로 카페 위치와 경로를 확인할 수 있습니다.

**이벤트 상태:**

| 상태 | 의미 |
|------|------|
| **모집중** (OPEN) | 참가 신청 가능 |
| **마감** (CLOSED) | 신청 마감, 선택 진행 중 |
| **완료** (COMPLETED) | 매칭 완료 |

**참가 신청 절차:**

```
이벤트 선택 → 참가 신청 → 주관자 승인 대기 → 승인 완료
```

1. 원하는 이벤트를 선택하고 **참가 신청**을 합니다.
2. 주관자가 프로필을 검토하여 **승인** 또는 **거절**합니다.
3. 결과는 앱 내 알림 + 카카오톡으로 안내됩니다.

### 4. 매칭

#### 이성 선택

- 이벤트 마감 시 승인된 참가자에게 **참가번호**가 자동 부여됩니다.
- 이성 참가자 목록에서 마음에 드는 상대를 선택합니다 (이벤트별 최대 선택 수 다름).
- 선택 마감 시간 전까지 선택을 완료해야 합니다.
- 선택 페이지에서 보이는 정보: 참가번호, 나이, 직업, 한줄 자기소개

#### 매칭 결과

- 선택 마감 후 시스템이 자동으로 매칭을 처리합니다.
- **양방향 매칭**: 서로 선택한 경우에만 매칭 성립
- 매칭 결과는 카카오톡 + 앱 내 알림으로 안내됩니다.
- 매칭된 상대의 닉네임이 공개됩니다.

### 5. 마이페이지

- **프로필 수정**: 프로필 정보 변경
- **나의 신청 내역**: 참가 신청 현황 및 이력 조회
- **알림**: 신청 결과, 매칭 결과, 리마인더 확인

## 주관자 가이드

### 1. 제휴 카페 확보

- 마켓플레이스에서 "장소를 제공합니다" 글을 탐색하거나, "장소를 찾습니다" 글을 등록합니다.
- 카페 주인에게 제휴 요청을 보내고, 수락되면 해당 카페에서 이벤트를 만들 수 있습니다.

### 2. 이벤트 운영

**이벤트 생성:**
- 제휴 카페 선택 → 이벤트 정보 입력 (날짜, 시간, 정원, 참가비, 선택 인원, 연령 제한)
- 생성된 이벤트 페이지 링크를 SNS에 공유하여 모객

**신청자 관리:**
- 카카오톡 알림으로 새 신청을 수신합니다.
- 카톡 버튼 클릭으로 승인/거절 가능 (로그인 없이)
- 웹 대시보드에서도 일괄 관리 가능

**매칭 처리:**
- 선택 마감 시간 도달 시 자동으로 매칭 처리
- 이벤트 결과 통계 확인 (참가자 수, 매칭 쌍 수)

### 3. 수수료

- 이벤트 완료 시 수수료가 자동 계산됩니다.
- 수수료 = 참가자 수 × 참가비 × 수수료율
- 플랫폼 관리자가 월말 청구 → 입금 확인

## 카페 주인 가이드

### 1. 카페 등록

- 플랫폼 관리자가 카페와 계정을 등록합니다.
- 로그인 후 카페 정보(이름, 주소, 설명, 사진)를 관리합니다.
- 카카오맵에서 카페 위치를 정확하게 등록합니다.

### 2. 제휴 관리

- 마켓플레이스에 "장소를 제공합니다" 글을 등록할 수 있습니다.
- 주관자로부터 제휴 요청이 오면 카카오톡 알림 + 웹에서 수락/거절합니다.
- 여러 주관자와 동시 제휴가 가능합니다.

### 3. 이벤트 확인

- 내 카페에서 진행되는 이벤트를 확인할 수 있습니다 (읽기 전용).
- 이벤트 전날 카카오톡으로 리마인더를 받습니다.

### 4. 수수료

- 이벤트 완료 시 중개 수수료가 자동 계산됩니다.
- 플랫폼 관리자가 월말 청구 → 입금 확인

## 알림 목록

| 수신자 | 알림 유형 | 시점 |
|--------|-----------|------|
| 주관자 | 새 신청 알림 | 참가자가 이벤트에 신청 |
| 주관자 | 이벤트 완료 | 매칭 완료 후 통계 |
| 주관자 | 수수료 청구 | 월말 수수료 청구 시 |
| 카페 주인 | 제휴 요청 | 주관자가 제휴 요청 |
| 카페 주인 | 이벤트 예정 | 이벤트 전날 리마인더 |
| 카페 주인 | 수수료 청구 | 월말 수수료 청구 시 |
| 참가자 | 승인/거절 | 신청 결과 |
| 참가자 | 선택 안내 | 선택 시간 시작 |
| 참가자 | 매칭 결과 | 매칭 성공/실패 |
| 참가자 | 이벤트 리마인더 | 이벤트 전날 |

알림은 **앱 내 알림 페이지**와 **카카오톡 채널 메시지**로 전달됩니다.
